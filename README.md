# Goo Engine

Some nix derivations to build [Goo Engine](https://www.dillongoostudios.com/gooengine)
for my personal use in Linux.

Builds only validated to run with AMD Radeon RX 9070 XT on x86_64 system
as that's the only hardware I have that is reasonable to run a 3D Engine.

Out of respect for the developer keeping their built binaries in their 
[patreon](https://www.patreon.com/dillongoo/posts/goo-engine-goo-4-145563253),
I will not be putting a github workflow to build and publish the binaries.

This is only set-up to help building with older versions of the dependency
libraries with nix determinism.
